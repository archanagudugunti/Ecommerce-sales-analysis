Project Title: E-commerce Sales Analysis

Project Overview
This project focuses on analyzing e-commerce sales data to understand sales performance, product performance, category-wise sales, quantity sold, and revenue.
The analysis was performed using Python in Jupyter Notebook, and an interactive dashboard was created using Power BI.

Tools & Technologies
Python
NumPy
Pandas
Jupyter Notebook
Power BI

Analysis Performed
Explored and cleaned the sales data
Analyzed total sales and total quantity
Identified the highest-selling products
Analyzed sales by category
Calculated average price per unit
Analyzed product and sales performance
Created visualizations and an interactive Power BI dashboard

Project Files
Jupyter Notebook: Contains the Python-based data analysis using NumPy and Pandas.
Power BI Dashboard: Contains interactive visualizations for analyzing e-commerce sales data.
